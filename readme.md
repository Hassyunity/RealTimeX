# RealTimeX ⚡

RealTimeX is a real-time chat application built with **Node.js**, **Express.js**, and **Socket.io**.  
It enables users to exchange messages instantly using **WebSockets**.

## 🚀 Features

- 📡 Real-time communication with WebSockets.
- 👥 Instant user connections.
- 💬 Live message sending and receiving.
- 🎨 Simple and fluid interface.

## 📦 Installation

1. **Clone the repository:**  
   ```bash
   git clone git@github.com:Hassyunity/RealTimeX.git
   cd RealTimeX
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the server:**
   ```bash
   node app.js
   ```

## 🚀 Deploying to Netlify

1. **Install Netlify CLI globally:**
   ```bash
   npm install netlify-cli -g
   ```

2. **Deploy your application:**
   ```bash
   netlify deploy
   ```

Once deployed, your application will be accessible at:
```
https://your-site-name.netlify.app/
```
